# GameEngineArchitecture

This repository holds the development plan for Alder, a C++20 game engine with Windows x64 as its first target. See the [English roadmap](docs/roadmap.en.md) or the [Chinese translation](docs/roadmap.zh-CN.md).

## Alder

The engine project lives in `Alder/`. For a checkout that includes Alder as a submodule, initialize it from the repository root.

```powershell
git submodule update --init --recursive
```

Open `Alder/` to develop the engine. The [Alder README](Alder/README.md) documents the CMake requirements, build commands, and output paths.
